# RePlay - Retro Gaming E-commerce

RePlay is an e-commerce project developed for Coderhouse, focused on retro gaming products such as video games, consoles, accessories, and peripherals, mainly from the PlayStation 2 and PlayStation 3 generations.

The project is being developed using ReactJS.

## Current Progress

The project is currently in development. So far, the following components have been created:

- **Navbar:** Main navigation bar for the website.
- **Cart Widget:** Shopping cart icon with an item counter.
- **ItemListContainer:** Temporary container for the main product listing section, receiving a welcome message through props.

## Current Work

I am currently working on **Coderhouse Delivery 3**, which consists of creating a dynamic product listing and implementing the product listing checkpoint.

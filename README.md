# RePlay - Retro Gaming E-commerce

RePlay is an e-commerce project developed for Coderhouse, focused on retro gaming products such as video games, consoles, accessories, and peripherals, mainly from the PlayStation 2 and PlayStation 3 generations.

The project is being developed using ReactJS.

## Current Progress

The project is currently in development. So far, the following components have been created:

- **Navbar:** Main navigation bar for the website.
- **Cart Widget:** Shopping cart icon with an item counter.
- **Hero:** Main introductory section of the website.
- **ItemListContainer:** Container responsible for managing and displaying the product listing.
- **ItemList:** Component that renders the list of products.
- **Item:** Individual product card.
- **ItemDetailContainer:** Container responsible for retrieving and managing individual product data.
- **ItemDetail:** Displays the complete information of a selected product.
- **ItemCount:** Quantity selector with stock validation and an Add to Cart button.

## Current Work

I am currently working on **Coderhouse Pre-Delivery 5**, which consists of implementing category navigation, individual product detail pages, and a shared layout using React Router DOM with nested routes, keeping the Navbar and Cart Widget visible across all pages.
